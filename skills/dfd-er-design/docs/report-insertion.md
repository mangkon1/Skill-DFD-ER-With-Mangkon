## 2. รูป (DFD / ER)

- ใช้ PNG จาก generator (**220 dpi**) หรือ Visio Export PNG ≥ 220 dpi พื้นขาว ห้ามใช้ภาพหน้าจอ
- แทรกแบบ **inline** (ไม่ลอย) ในย่อหน้าของตัวเอง: กึ่งกลาง, `keepNext`, spacing before 80 twips, ล็อกอัตราส่วน (noChangeAspect)
- ความกว้างในเล่ม (ค่าที่ใช้จริง):

| รูป | ขนาดในเล่ม (in) | เหตุผล |
|---|---|---|
| ภาพที่ 3.1 Context Diagram | 5.76 × 3.47 | เต็มความกว้างพื้นที่พิมพ์ |
| ภาพที่ 3.2 DFD Level 1 | 4.28 × 7.74 | จำกัดด้วยความสูง ให้รูป + คำบรรยายอยู่หน้าเดียวกัน |
| ภาพที่ 3.3–3.4 DFD Level 2 | 5.50 × (ตามสัดส่วน) | ทุก Level 2 กว้างเท่ากัน |
| ภาพที่ 3.5 ER Diagram | 8.30 × 4.81 | หน้าแนวนอน รูปเดียวทั้ง ER |

- ตัวอักษรในรูปหลังย่อต้องอ่านได้ (ไม่ต่ำกว่า ~10 pt เมื่อพิมพ์) ถ้าเล็กเกิน ให้ลดจำนวนข้อความในป้าย ไม่ใช่ลดขนาดฟอนต์
- **แทนรูปเดิมโดยไม่แตะข้อความ**: แทนไฟล์ใน `word/media/imageN.png` ของ .docx ด้วยรูปใหม่ (ชื่อเดิม) และคง `wp:extent` เดิม ถ้าสัดส่วนรูปเปลี่ยน ให้ปรับ cy = cx × (H/W) ทั้ง `wp:extent` และ `a:ext`
  Word จะเปลี่ยนชื่อ/ลำดับ media เมื่อบันทึก ให้ map imageN ↔ รูป จาก `document.xml.rels` ทุกครั้ง อย่าเดาจากชื่อไฟล์

## 3. คำบรรยาย (caption)

## 5. เลขหน้า

- ส่วนนำ (กิตติกรรมประกาศ บทคัดย่อ สารบัญ สารบัญตาราง สารบัญภาพ): **เลขโรมัน** `pgNumType fmt=upperRoman` (ตัวอย่างเริ่มที่ IV)
- เนื้อหา: เลขอารบิก เริ่ม 1 ที่บทที่ 1 และกำหนด `pgNumType start` ของแต่ละไฟล์บทให้ต่อกัน (ตัวอย่าง: บท 1 = 1, บท 2 = 9, บท 3 = 28, บรรณานุกรม = 49)
- เลขหน้าอยู่ **header ชิดขวา** (ไฟล์ตัวอย่างแสดงเลขทุกหน้ารวมหน้าแรกของบท ถ้าแบบของมหาวิทยาลัยให้ซ่อนหน้าแรก ใช้ titlePg); หน้าแนวนอน (ER) มี header ของตัวเองที่ใช้กล่องข้อความหมุนเลขหน้า ให้อยู่ตำแหน่งเดียวกับหน้าแนวตั้งเมื่อพลิกเล่ม
- หลังเปลี่ยนรูป ให้ render PDF แล้วตรวจว่าหัวข้อ รูป และตาราง ยังอยู่หน้าเดิม ถ้าเลื่อน ต้องแก้สารบัญ

## 6. สารบัญ สารบัญภาพ สารบัญตาราง

- สารบัญในไฟล์ตัวอย่างเป็นตารางพิมพ์เอง (ไม่ใช่ field) ใช้ tab ขวามี dot leader (`w:tab val=right leader=dot`)
- แก้เลขหน้าโดยแก้ `w:t` ทีละตัว **อย่าแทนข้อความทั้งเซลล์** (dot leader และ tab จะหาย)
- ลำดับในสารบัญภาพต้องเรียงตามเลขภาพ ตรวจทุกครั้งที่เพิ่ม/ลบรูป
- ถ้าเล่มใช้ TOC field ของ Word: กด Update Field (Entire table) แล้วตรวจกับ PDF

## 7. การแก้ข้อความโดยไม่ทำลายรูปแบบ

- แทนข้อความเฉพาะคำที่ต้องเปลี่ยน ภายใน run เดิม อย่าแทนข้ามหลาย run (จะทำให้ bold/cs/ขนาดเปลี่ยน)
- run ภาษาไทยต้องคง `<w:cs/>` และ szCs/bCs; ตรวจด้วยการเปิด PDF ดูตัวหนา/ขนาดหลังแก้
- คำที่ห้ามตัดบรรทัด (เช่น "พิมพ์ครั้งที่ 6") ใช้ non-breaking space (U+00A0)
- อย่าใช้ `pageBreakBefore` ซ้อนกับ page break อื่น (เกิดหน้าว่าง)
- ตารางที่สร้างด้วย python-docx ต้องตั้ง tblGrid + tblLayout fixed ไม่งั้นความกว้างไม่ตามที่กำหนด
